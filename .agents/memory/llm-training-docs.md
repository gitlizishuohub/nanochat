# LLM 训练文档位置

事实或决策：用户要求将过大的《LLM模型训练完整流程与术语对照.md》在 docs 中新开栏目拆分。正文现位于 `.agents/docs/llm-training-workflow/`，根目录同名文件保留为简短导航入口。用户随后明确要求英文命名，新栏目文件名统一采用英文，中文正文保留。

Why: 原文约 196 KB，术语表占约 85 KB；按章节及六类术语拆分，方便阅读与局部维护；2026-10-15 按用户要求对齐当前技能，修复排序、标题层级、悬停标记及 Mermaid 边标签。

How to apply: 从栏目 README 查找章节；本栏目新增或重命名文件沿用英文命名；术语入口为 `12-0-glossary-index.md`，排序先于六篇术语表。独立正文以一级标题起始；正文术语使用原生 `<abbr title="…">` 悬停，邻近独立“释义”链接跳转；维护 `ref-` / `term-` 往返锚点，不将术语本身改成链接。Mermaid 的分支说明放在节点中，箭头不附文字。源码依据仍为原文的 2026-10-12 核对记录，拆分不代表新的源码或运行验收。

Evidence: 用户在 2026-10-13 明确要求“文件过大，在docs中新开栏目拆封”；同日用户补充“英文命名”；2026-10-15 用户要求制定计划并按当前技能修改；结果见 [栏目目录](../docs/llm-training-workflow/README.md) 及根目录同名入口。

Invalidates: 用户调整文档位置、章节结构或重新核验源码时更新本条；源码变化后不得沿用原核对结果作为当前结论。
